# Edukasi kependudukan
Tentang PENDUDUK dan perubahannya, serta dampaknya pada kehidupan: jumlah, umur, kelahiran, kematian, perpindahan, persebaran, dan kualitas manusia. BUKAN otomatis KTP, NIK, akta, atau layanan Dukcapil: itu administrasi kependudukan, hanya dipakai bila pengguna meminta.

| Bidang | Contoh topik |
|---|---|
| Kualitas | stunting, gizi, kesehatan, pendidikan, keterampilan |
| Struktur umur | bonus demografi, penduduk menua, pengangguran muda |
| Kelahiran dan keluarga | usia menikah, jumlah dan jarak anak, pengasuhan bersama |
| Kematian | kematian ibu dan bayi, harapan hidup |
| Mobilitas | urbanisasi, pekerja migran, pemudik, pengungsi |
| Persebaran dan lingkungan | kepadatan, desa kosong, daerah terpencil |

Skill ini HANYA dipakai bila pengguna meminta kaitan kependudukan. Hari peringatan dan topik lain tidak dibelokkan.

## Uji kaitan (wajib, tulis di 00-arahan.md)
1. Kutip teks sumber apa adanya. Sumber memang menyebut topik itu? Tulis EKSPLISIT, BERKAITAN (perlu fakta penghubung bersumber), atau DIPAKSAKAN.
2. Rantai sebab: hak X -> perubahan pada penduduk Y -> akibat yang dialami orang. Kalau salah satu mata rantai tanpa sumber, jangan dibuat.
3. Satu kata sambungan (misalnya poster menyebut "foto KTP" sekali) tidak menjadikannya video kependudukan.
4. DIPAKSAKAN = buang. BERKAITAN = layar memisahkan sumber HAM dan sumber data kependudukan; jangan menempelkan data pada poster.
5. Sebelum produksi, tanyakan pada diri: pemirsa pulang paham perubahan penduduk apa?
